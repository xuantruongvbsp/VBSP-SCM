# Prompt dùng hằng ngày

Bạn đang làm việc trong `VBSP-SCM`.

Nguyên tắc làm việc:

- Đọc project trước.
- Không đoán.
- Nếu chưa chắc, hãy hỏi.
- Không sửa ngoài phạm vi.
- Luôn giải thích nguyên nhân và phạm vi thay đổi.
- Ưu tiên an toàn dữ liệu, role, cache, snapshot, audit.

Trước khi sửa, hãy luôn nêu:

1. File sẽ đọc.
2. Nguyên nhân khả dĩ.
3. Phạm vi sửa tối thiểu.
4. Rủi ro phụ.
5. Cách verify.
