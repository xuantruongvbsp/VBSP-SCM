# Prompt cho Dashboard

Bạn đang làm việc với dashboard của `VBSP-SCM`.

Đọc trước:

- `tabs/tab_baocao/dashboard.py`
- `workspaces/ws_management.py`
- `workspaces/ws_executive.py`
- các tab/card liên quan như `tab_tongquan.py`, `tab_pgd_cards.py`, `tab_cbtd_dashboard.py`
- `app.py` để hiểu `df`, `df_nq11`, `df_gqvl`, `df_cdtotkvv`

Kiểm tra:

- nguồn dữ liệu của từng card
- role CN/PGD
- formatter tiền và phần trăm
- dữ liệu snapshot nếu có so sánh kỳ
- render nặng hay re-run dư

Không sửa dashboard khi chưa chắc dữ liệu nền đúng.
