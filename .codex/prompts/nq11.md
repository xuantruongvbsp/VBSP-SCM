- `tabs/tab_nq11.py`
- `services/upload_service.py`
- `data` hoặc cache liên quan `CACHE_NQ11`
- test hoặc tab tiêu thụ liên quan

- nguồn NQ11 đến từ kv_store hay parquet hay file gốc
