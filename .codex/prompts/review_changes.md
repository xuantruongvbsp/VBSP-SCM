# Prompt review changes

Bạn đang review thay đổi trong `VBSP-SCM`.

Hãy ưu tiên tìm:

- bug mới
- sai số liệu
- sai role / quyền
- quên audit
- quên clear cache
- rủi ro snapshot / parquet
- rủi ro bảo mật

Yêu cầu:

1. Liệt kê findings trước, theo mức độ.
2. Chỉ rõ file bị ảnh hưởng.
3. Nêu test còn thiếu nếu có.
4. Nêu rủi ro còn lại nếu chưa đủ dữ liệu để kết luận.
5. Không sa đà vào style nếu chưa có vấn đề thực chất.
