🎯 Khuyến nghị cho VBSP-SCM
💼 Task thường (CRUD, tab đơn giản)
  • DeepSeek V4 hoặc V4 Pro viết code
  • Haiku review syntax/convention
  • Sonnet audit nếu logic phức tạp
  • V4: ~30% / V4 Pro: ~40%
🧠 Task phức tạp (merge, snapshot, báo cáo)
  • R1 phân tích thiết kế
  • V4 Pro viết code chính
  • Sonnet audit & finalize
  • Tổng chi phí: ~55%
🔧 Fix bug & review code
  • Haiku phát hiện lỗi nhanh
  • Sonnet sửa logic nếu cần
  • Không cần R1 hay V4
  • Tổng chi phí: ~20%
🏆 Quan trọng (production-critical)
  • Chỉ Sonnet làm trọn gói
  • Không phối hợp, không tiết kiệm
  • Chất lượng cao nhất, 0 lần sửa
  • Tổng chi phí: 100% (xứng đáng)

💡 Kết luận (đã cập nhật — có V4 Pro)

V4 Pro là "sweet spot" nằm giữa V4 thường và Sonnet — chất lượng code 8,5/10, giá chỉ ~40-50% Sonnet, có ngữ cảnh 1M tokens. Đây là lựa chọn kinh tế nhất cho dự án VBSP-SCM vì bạn không cần Haiku review trung gian, V4 Pro tự viết đã tương đối sạch.

⚖️ Tỷ lệ vàng mới: 50% task → tôi (Sonnet) làm chính (quan trọng), 40% task → V4 Pro tự xử (tiết kiệm), 10% → Haiku fix nhanh. So với dùng V4 thường, bạn không cần mất công review gắt — V4 Pro tự cho output khá clean rồi.

📌 Chú thích: Chi phí ước tính dựa trên giá API công khai (5/2026). "Phối hợp" giả định bạn chuyển context qua lại giữa các công cụ (Trae IDE, Windsurf, chat riêng). Thực tế có thể chênh lệch tuỳ độ dài prompt và số lần retry.
