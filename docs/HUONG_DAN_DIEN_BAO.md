# 📡 Hướng dẫn sử dụng Điện báo — Phân hệ Phòng KH-NV

> VBSP-SCM · Workspace **Phòng KH-NV** (`ws_management`) · Cập nhật: 05/2026

### 📌 Tóm tắt nhanh

1. **Điện báo là gì?** — File Excel tổng hợp số liệu tín dụng / cân đối nguồn vốn **cấp Chi nhánh**.
2. **Tải mẫu ở đâu?** — **Báo cáo nhanh → Báo cáo theo công thức → Điện báo ngày → Chọn tick tất cả** (theo menu nội bộ VBSP).
3. **Hai cột chính trong mỗi file** — **Cột B** = tên chỉ tiêu (text), **Cột C** = giá trị số. Upload **hai file riêng**: hiện tại + 31/12 năm trước, cùng cấu trúc.
4. **Cách upload** — Tải mẫu, điền số liệu → mở tab **📡 Điện Báo** → kéo xuống **Upload file Điện báo** → chọn từng file (chọn xong hệ thống tự xử lý).
5. **Lưu ý** — Đơn vị số khớp mẫu; upload mới ghi đè bản cũ; chỉ **admin** / **manager** được upload.
