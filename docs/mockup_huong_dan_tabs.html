📊 Dữ liệu & Upload

Dữ liệu không cập nhật

  • Kiểm tra file đã merge chưa (CN)
  • Reload trang (Ctrl+Shift+R)
  • Xem tab Trạng thái hệ thống

Lỗi upload file

  • Kiểm tra đúng mẫu file
  • Tên file đúng slug PGD
  • File không bị khoá/mở bởi Excel

Dữ liệu PGD vs CN lệch

  • Phân hệ CN đọc cache parquet đã merge
  • Phân hệ PGD đọc file upload riêng
