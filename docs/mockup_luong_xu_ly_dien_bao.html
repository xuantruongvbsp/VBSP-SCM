📐 SO SÁNH 2 FORMAT

❌ Format Cũ (3 cột)

Chỉ đọc được cột B/C → bỏ qua 21 PGD

# Cột B = tên chỉ tiêu, Cột C = giá trị for row in rows: ten = row[1] ← cột B val = row[2] ← cột C (chỉ có Cộng) rows.append({"ten": ten, "val": val})
  • Không biết số liệu từng PGD
  • Tên chỉ tiêu hardcode ~30 dòng
  • Không đọc được sheet khác

✅ Format Mới (Ma Trận)

Đọc toàn bộ 22 cột PGD × tất cả sheet

# Cột B = tên, Cột C = Cộng, D→... = từng PGD data = doc_dienbao_matrix(fp, sheet="M") # Trả về: data["rows"] ← list chỉ tiêu + giá trị Cộng data["units"] ← [HST, L.Thành, T.Bom, ...] data["matrix"] ← {"Hộ nghèo": {"HST":0.1, "T.Bom":2.6,...}}
  • Đầy đủ 22 đơn vị
  • Tự động phát hiện chỉ tiêu
  • Đọc được tất cả 7 sheet
  • Ma trận chỉ tiêu × đơn vị
