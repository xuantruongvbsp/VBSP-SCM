```

│  1. Chọn bộ lọc │────▶│  2. Xem bảng    │────▶│  3. Chọn loại PDF       │
│     (PGD/Xã)    │     │   tổng hợp/     │     │                         │
│                 │     │   chi tiết      │     │  ┌─────────────────┐     │
└─────────────────┘     └─────────────────┘     │  │ • PDF Pivot     │     │
                                                │  │   (Tổng hợp)    │     │
                                                │  │ • PDF Chi tiết  │     │
                                                │  │   (Danh sách)   │     │
                                                │  │ • PDF theo Nhóm │     │
                                                │  │   (Section)     │     │

                                                └─────────────────────────┘
                                                          │

                                                ┌─────────────────────────┐
                                                │  4. Tải file PDF        │

```

## API Tích hợp

```python
# Trong tab_baocao.py — Mảng Tổng hợp
col1, col2, col3 = st.columns(3)
with col1:
    st.download_button("📥 Xuất Excel", ...)
with col2:
    if st.button("📄 Xuất PDF Pivot"):
        pdf_bytes = xuat_pdf_pivot(
            df=dbc_raw,
            group_col=group_cols[0],  # Cột đang group
            tieu_de=f"Tổng hợp theo {group_label}",
            nguoi_xuat=username,
            prefix_file="tong_hop"
        )
        st.download_button("⬇️ Tải PDF", pdf_bytes, ...)
        db.ghi_audit(username, "xuat_pdf_pivot", ...)

with col3:
    if st.button("📄 PDF theo Nhóm"):
        pdf_bytes = xuat_pdf_theo_nhom(...)
        ...

# Trong tab_baocao.py — Mảng Chi tiết
col_pdf1, col_pdf2 = st.columns(2)
with col_pdf1:
    if st.button("📄 PDF Chi tiết"):
        pdf_bytes = xuat_pdf_chi_tiet(df_chitiet, COL_CHUNG, ...)
        ...
with col_pdf2:
    if st.button("📄 PDF theo Nhóm"):
        pdf_bytes = xuat_pdf_theo_nhom(df_chitiet, group_col, ...)
        ...
```

## Câu trả lời câu hỏi còn mở

| Câu hỏi | Đề xuất |
|---------|---------|
| 1. Cột chi tiết Loại 3 dùng gì? | Dùng `COL_CHUNG` của tab_baocao (đã có sẵn) |
| 2. Có cần PageBreak giữa nhóm? | Không — Dùng `KeepTogether` để nhóm không bị cắt ngang trang |
| 3. Agg cols cho Loại 1? | Mặc định: `["Số KH", "Số món", "Tổng dư nợ", "TH", "QH", "%"]` |
